# 🏎️ Excel-гонка

Онлайн-игра для студентов СПО по теме **«Функции ссылок и массивов»** в Microsoft Excel.

## 🎯 Описание

Образовательная игра в формате викторины с таймером. Студент отвечает на 20 вопросов разных типов, набирает баллы и получает оценку по 10-балльной шкале.

## ✨ Возможности

- 🔀 **Случайный порядок вопросов** и вариантов ответов
- 📝 **4 типа вопросов:**
  - 🔘 Один правильный ответ
  - ☑️ Несколько правильных ответов
  - ✔️ Верно / Неверно
  - ✍️ Заполнить пропуск в формуле
- ⏱️ **Таймер 20 секунд** на каждый вопрос
- 💨 **Бонус за скорость** (до +10 баллов)
- 🏁 **Анимация гонки** — машина движется по трассе
- 📊 **Экспорт результата в Excel** (.xls)
- 📧 **Отправка результата преподавателю** по email
- 🏆 **Таблица лидеров** (сохраняется локально)
- 🎨 **Синяя цветовая гамма** — глубокий синий с оттенками

## 🎮 Как играть

1. Откройте файл `index.html` в браузере или перейдите по ссылке GitHub Pages.
2. Введите имя и группу.
3. Отвечайте на вопросы — у вас 20 секунд на каждый.
4. После завершения скачайте Excel-файл и отправьте преподавателю.

## 📋 Проверяемые функции

✅ ВПР, ГПР, ПОИСКПОЗ, ИНДЕКС, СТРОКА, СТОЛБЕЦ, ТРАНСП  
✅ СУММЕСЛИ, СУММЕСЛИМН, СЧЁТЕСЛИ, СЧЁТЕСЛИМН  
✅ СРЗНАЧЕСЛИ  
❌ Не проверяются: СМЕЩ, ДВССЫЛ, массивные формулы

## 🎯 Система оценки (10-балльная)

| Баллы | Оценка | Статус |
|-------|--------|--------|
| 0–80 | 0–2 | Неудовлетворительно |
| 81–160 | 3–4 | Слабо |
| 161–240 | 5–6 | Удовлетворительно |
| 241–320 | 7–8 | Хорошо |
| 321–400 | 9–10 | Отлично |
